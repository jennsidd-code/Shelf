# Shelf

A beauty and skincare inventory app. Snap photos of products (Claude fills in brand, name, category and actives) or scan barcodes with the camera.

- Works offline and installs to your home screen (Share → Add to Home Screen).
- Your inventory is stored only on your device. Use Settings → Save backup to keep a copy or move to a new phone.
- Photo auto-fill uses your own Claude API key (Settings ⚙︎), stored only on your device.
